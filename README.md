# ma7m0ud.github.io

Personal site for Mahmoud Abdelrahman — Payments & Fintech Engineer.

Plain HTML/CSS/JS, no build step, hosted on GitHub Pages.

## Structure

- `index.html` — home page (about, experience, skills, contact)
- `blog.html` — blog listing page
- `assets/css/style.css` — styles
- `assets/js/main.js` — mobile nav + small helpers

## Local preview

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000

## Deploy

Push to the `master` branch — GitHub Pages serves the repo root directly.
